Исходные векторы:
v1 = Vector[5]: (1, 2, 3, 4, 5)
v2 = Vector[5]: (2, 4, 6, 8, 10)

Работа operator[]:
v1[0] = 1
После v1[0] = 999: v1 = Vector[5]: (999, 2, 3, 4, 5)

Конструктор копирования:
vCopy (копия v2) = Vector[5]: (2, 4, 6, 8, 10)

Конструктор перемещения:
vMoved (перемещённый vCopy) = Vector[5]: (2, 4, 6, 8, 10)
vCopy после перемещения = Vector[0]: ()

Присваивание с копированием:
v3 = v2 (копия): v3 = Vector[5]: (2, 4, 6, 8, 10)

Присваивание с перемещением:
v4 (перемещённый v3) = Vector[5]: (2, 4, 6, 8, 10)
v3 после перемещения = Vector[0]: ()

Операция сравнения Vector < int*:
Массив arr[5]: (0, 2, 3, 4, 5)
v2 (обрезанный до длины 5) = Vector[5]: (2, 4, 6, 8, 10)
v2 < arr  =>  false
vEq = Vector[5]: (0, 2, 3, 4, 5)
vEq < arr => false (равные элементы - ложь)
vGreater = Vector[5]: (100, 2, 3, 4, 5)
vGreater < arr => false (первый больше - ложь)
vLess = Vector[5]: (-100, 2, 3, 4, 5)
vLess < arr => true (первый меньше - истина)
